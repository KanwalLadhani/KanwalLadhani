I'm a third-year Software Engineering student who builds real, tested backend systems rather than tutorial clones. My work centers on **Java** and a self-directed transition into **Spring Boot**, with a strong emphasis on clean **layered architecture** (Controller–Service–Repository–Entity), the **DTO pattern**, and **dependency injection**.

Every project I ship is backed by intentional design decisions — from refactoring monolithic scripts into Maven-managed, testable services, to writing unit tests that don't depend on a live database connection. I care about backend code that is structured, verifiable, and built to be maintained.

- Backend / Software Engineering Internships

- Open Source Contributions (Java / Spring ecosystem)
